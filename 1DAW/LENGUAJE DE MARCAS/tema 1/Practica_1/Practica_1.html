Llenguatge de Marques

¿Què es el llenguatge de marques?

El llenguatge de marques és un sistema per a codificar un document que combina text amb etiquetes o marques per a definir la seva estructura, significat o presentació. A diferència dels llenguatges de programació, no tenen lògica algorítmica, variables ni funcions aritmètiques; només organitzen i descriuen la informació

Alguns lenguatges de marques son

  • HTML
  • XML
  • Markdown

Aquest son els llenguatges principals que podem trobar.

Algunes caracteristiques son

  1. Text pla:  Es componen de caràcters llegibles sense elements binaris.
  2. Ús d'etiquetes: Empren marques (normalment entre símbols com < >) per a envoltar el contingut.
  3. No són executables: Un navegador o un processador llegeix i representa el contingut, però no executa codi informàtic de control de flux.
