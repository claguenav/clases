
| Comando | Para qué sirve |
| --- | --- |
| `git add .` | Prepara todos los archivos modificados. |
| `git commit -m "Mensaje"` | Guarda los cambios con una descripción. |
| `git push` | Sube los cambios a internet. |
| `git status` | Comprueba qué archivos se han cambiado. |
| `git pull` | Descarga cambios si da error al subir. |
